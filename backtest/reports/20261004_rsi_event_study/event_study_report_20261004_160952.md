# RSI 신호 분해 event study (1단계)

**실행:** 2026-10-04 16:09:58 (KST) | **DB:** backtest_data | **기간:** 20160101 ~ 20260630 | **bootstrap:** 1000회

**목적:** 현행 복합 신호(RSI(2)<3 AND 2일하락률<-5%)를 구성 요소(A/B/C)로 분해해 각 신호의 사후 수익률 정보량을 대조군(시장효과) 대비 초과수익으로 검증한다.

## 데이터 및 방법

- 데이터: `validation_common.load_all("backtest_data")` (2,962종목), 유니버스 prev_month 정렬(룩어헤드 방지), 월별 상위 250 스냅샷.
- 지표: RSI(2) Wilder(`util/rsi_calc.compute_rsi`), MA200(rolling 200), 2거래일 하락률=(close-shift(2))/shift(2).
- 신호 조건: **모두 close > MA200** 하에서 정의. 대조군 = 같은 날짜·유니버스 내 비신호 종목(close>MA200).
- 체결: 신호일 종가 t → 익일 시가 진입 open(t+1) → open(t+1+h) 시가 청산, h∈{1,2,3,5}. 시가 부재시 종가 fallback + 결측 플래그. **주 판단기간 h=3 (사전 지정).**
- 갭수익 close(t)→open(t+1) 별도 집계 (진입 시점을 개장가로 고정하므로 trade P&L은 open→open).
- 부트스트랩: 날짜 단위 resample 1000회, 90% CI(2.5~97.5 백분위). 날짜 내 종목 간 의존성 보존.
- 비용: 수수료 0.015%×2 + 거래세 0.20% = **0.23% 고정** + 슬리피지(기본 편도 0.2% → 왕복 0.40%). 기본 왕복 총비용 = **0.63%**. 민감도 표 참조.

적격 유니버스-일 행 수: **357,812** (close>MA200 & prev_month 유니버스).

## 재현 주의점

- 유니버스 스냅샷은 반드시 **prev_month** 정렬 (당월 사용 시 룩어헤드). 첫 스냅샷(201601)은 전월 부재로 당월 폴백.
- 종목별 자체 거래일 기준 t+1/t+1+h (개별 종목 휴장/상장폐지 시 종가 fallback + 플래그 집계).
- 대조군은 close>MA200 적격 유니버스 내 비신호 종목. 신호 간 종목 중복은 의도됨 (B⊂C 성립 구조 아님, A·B 각각 독립 평가).
- 신호일 종가 대비 익일 시가 진입이므로 갭은 별도 집계이며 trade 수익률에는 미포함.
- 비용은 편도 슬리피지 가정에 민감 — 기본 0.2% 명시, 민감도 표로 범위 제시.
