# 전향적 관찰 프로토콜 — 복합신호 C (신호 C · h=3 고정)

**버전:** 1.0 | **작성:** 2026-10-04 (feature/strategy-research)

## 1. 목적

2.5/3단계에서 확인된 복합신호 C의 비용후 마진(+0.29%)과 매칭 대조 추가기여(+0.45%)가
실시간(전향적) 환경에서도 유지되는지 **관찰만으로** 검증한다. 관찰 기간에는 신호·파라미터·
유니버스·비용을 변경하지 않는다 (파라미터 최적화·유니버스 확장·실전 승격 금지).

## 2. 관찰 대상 (고정)

- **신호 C**: RSI(2) < 3 AND 2거래일 하락률 < −5% AND close > MA200
  - RSI(2): Wilder, period=2, min_periods=2 (`util/rsi_calc.compute_rsi`)
  - 2거래일 하락률(%): (close − close.shift(2)) / close.shift(2) × 100
  - MA200: close.rolling(200, min_periods=200).mean()
- **보유기간 h = 3** (고정, 주 판단기간)

## 3. 유니버스 (고정)

- 월별 상위 250 스냅샷, **prev_month 엄격 정렬**: 해당 거래월의 전월 스냅샷에 포함된
  종목만. 전월 스냅샷 부재 월(예: 201601)은 유니버스 없음(fallback 금지).
- 종목 가용기간(availability_map) 내에서만 관찰.

## 4. 체결 모델 (고정)

- **진입**: 신호일 종가 t 기준, 다음 시장 거래일 시가 open(t+1). **시가만, 대체 없음.**
- **청산**: open(t+1+3) 시가. **시가만, 대체 없음.**
- **시장 거래일 캘린더**: 전 종목 거래일 합집합(공통 캘린더).

## 5. 제외 규칙 (사유코드)

| 사유코드 | 정의 | 처리 |
|----------|------|------|
| `OK` | 진입·청산 시가 모두 확정 | 수익률 집계에 포함 |
| `ENTRY_MISS` | 진입 시가 확정불가(미체결 가정) | **미관찰** — 미체결율에 집계, 수익률 제외 |
| `EXIT_MISS` | 진입 후 청산 시가 확정불가(보유 리스크) | 수익률 제외, **별도추적**(보유 중 상태 기록) |
| `HALT` | 거래정지(청산일 행 없음 + 당월 유니버스 존재) | EXIT_MISS의 사유 세분 |
| `DELIST` | 상장폐지·가용기간종료(청산일 > 마지막 행) | EXIT_MISS의 사유 세분 |
| `ARTIFACT` | 행 존재하나 시가 0(수정주가 아티팩트) | EXIT_MISS의 사유 세분 |
| `UNKNOWN` | 판별 불가 | EXIT_MISS의 사유 세분 |

## 6. 기록 스키마 (레코드 1행 = 관찰 1건)

| 필드 | 설명 |
|------|------|
| `observe_date` | 관찰일(신호일) YYYYMMDD |
| `code` | 종목코드(6자리) |
| `name` | 종목명 |
| `rsi2` | 신호값 RSI(2) |
| `drop2_pct` | 신호값 2거래일 하락률(%) |
| `close` | 신호일 종가 |
| `ma200` | MA200 |
| `in_universe` | 유니버스 적격 여부(Y/N) |
| `entry_date` | 진입일(시장 거래일 t+1) |
| `entry_price` | 진입 시가 |
| `exit_date` | 청산일(시장 거래일 t+1+3) |
| `exit_price` | 청산 시가 |
| `qty_assumption` | 수량가정 = 500만원 / entry_price (가정 포지션 500만원) |
| `cost_assumption_pct` | 0.63 (수수료 0.015%×2 + 세금 0.20% + 슬리피지 편도 0.2%×2) |
| `ret_pct` | (exit_price/entry_price − 1) × 100 |
| `ret_after_cost_pct` | ret_pct − 0.63 |
| `reason_code` | §5 사유코드 |

## 7. 평가지표 (관찰 누적 후)

- 관찰 건수(OK), 미체결율(ENTRY_MISS / 전체 신호), 청산불가율(EXIT_MISS / 진입성공)
- 평균 수익률, 비용후 평균(절대순수익), 표준 대조군 대비 초과
- 매칭 대조(같은 날짜 & drop2 ±1%p, RSI>=3) 추가기여
- 날짜블록 bootstrap 95% CI (블록 5거래일)
- 보유 리스크(EXIT_MISS) 건수·사유 분해 — 수익률에서 제외하고 별도 보고

## 8. 중단/연장 조건 (사전 고정)

- **연장**: 관찰 N주(또는 40건 이상 OK) 후에도 비용후 평균 > 0 이면 계속 관찰.
- **중단**: 아래 중 하나 충족 시 관찰 중단
  - OK 누적 20건 미만(관찰 밀도 부족)이 6개월 지속
  - 누적 OK 40건 이상에서 비용후 평균 ≤ 0
  - 미체결율(ENTRY_MISS) 50% 초과 또는 청산불가율(EXIT_MISS) 30% 초과
- 관찰 중 신호·파라미터·유니버스·비용 변경 금지.

## 9. 미래정보 사용 금지

- 관찰일 이후의 **고가·저가·거래량·이후 가격**을 신호 판단·필터에 사용 금지.
- 진입·청산 판정은 **시가와 종가(신호 판단용)만** 사용. 사후 필터(예: "상한가였으면 제외",
  "거래량 큰 날만") 금지 — 관찰 기록에만 사실로 남긴다.
- 수정주가(FDR/Naver) 한계: 시가 결손(0) 행은 ARTIFACT로 기록하고 가격 대체 금지.
